# Todo List GUI

A simple Todo List GUI built with Python, Streamlit and Pydantic.

I made this project while learning how to use external Python libraries and how to structure a small Python application.

## What I used

* Python
* Streamlit
* Pydantic
* uv

## Features

* Add tasks
* Remove tasks
* Update tasks
* Mark tasks as completed
* Save and load tasks

## Running it

```bash
uv run streamlit run app.py
```

## Why I made this

Mostly to practice using external libraries and putting together a small project from scratch.
